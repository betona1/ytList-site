Privacy Policy

Effective 2026-11-05 · 개인정보처리방침

ytList ("the Tool") is an internal application operated by our company for its employees. It is not offered to the public. This policy explains what data the Tool handles and how.

ytList("도구")는 당사 직원을 위한 사내 전용 애플리케이션이며 일반에 제공되지 않습니다. 이 문서는 도구가 어떤 데이터를 어떻게 다루는지 설명합니다.

1. Data obtained from YouTube

The Tool uses the YouTube Data API v3 to retrieve public information only: video metadata (ID, title, description, tags, thumbnail URL, publish date, duration, licence, category, default language), public channel metadata (ID, name, thumbnail URL, subscriber count) and public statistics (view, like and comment counts). It does not access any YouTube account, and it never requests user authorization (OAuth). No comments, subscriptions, watch history, playlists or other user data are collected.

YouTube Data API v3 로 공개 정보만 받습니다: 영상 메타데이터, 공개 채널 메타데이터, 공개 통계. YouTube 계정에 접근하지 않으며 사용자 인증(OAuth)을 요청하지 않습니다. 댓글·구독·시청기록·재생목록 등 사용자 데이터는 수집하지 않습니다.

2. Retention

Statistics (view, like and comment counts) are stored as time-series snapshots for no longer than 30 days and are deleted automatically by the collector, in accordance with the YouTube API Services Developer Policies. Video and channel metadata is kept so that lists can be filtered without repeated API calls, and is refreshed from the API when a video reappears in the chart. Data for videos that no longer appear in any chart is pruned periodically.

통계 스냅샷은 최대 30일 보관 후 수집기가 자동 삭제합니다. 영상·채널 메타데이터는 목록 필터링을 위해 보관하며 차트에 다시 나타나면 API 값으로 갱신됩니다.

3. Data about employees who use the Tool

The Tool has no sign-in and no user accounts. It sets no cookies and uses no analytics or tracking. Bookmarks and notes made in the Tool are stored on the internal server without any user identifier. The web server keeps standard access logs (internal IP address, request path, time) for operational purposes only, rotated within 30 days.

로그인·계정이 없고, 쿠키·분석 도구·추적을 쓰지 않습니다. 북마크·메모는 사용자 식별자 없이 사내 서버에 저장됩니다. 서버 접근 로그(사내 IP·경로·시각)는 운영 목적으로만 보관하며 30일 내 순환 삭제됩니다.

4. Sharing and transfer

Data is stored on a single server inside the company network. It is not sold, redistributed, published, transferred to third parties, merged with other data sources or used for advertising. The only external service the Tool communicates with is Google's YouTube Data API and the official YouTube IFrame Player.

데이터는 사내망의 서버 한 대에만 저장되며 판매·재배포·공개·제3자 제공·다른 데이터와의 결합·광고 이용을 하지 않습니다. 통신하는 외부 서비스는 YouTube Data API 와 공식 YouTube IFrame 플레이어뿐입니다.

5. Security

The Tool is reachable only from the internal network. The API key is kept in a server-side configuration file and is never shown in the interface or written to logs. Access to the server is limited to the administrators.

도구는 사내망에서만 접속되며, API 키는 서버 설정 파일에만 있고 화면·로그에 노출되지 않습니다. 서버 접근은 관리자에게 한정됩니다.

6. Google and YouTube policies

The Tool uses YouTube API Services. By using the Tool, employees agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Because the Tool never accesses a user's YouTube account, there is no authorized data to revoke; the Tool holds no per-user Google data.

도구는 YouTube API 서비스를 사용하며, 사용자는 YouTube 서비스 약관에 동의하는 것으로 간주됩니다. 구글의 데이터 처리는 구글 개인정보처리방침을 따릅니다. 도구는 사용자의 YouTube 계정에 접근하지 않으므로 철회할 인가 데이터가 없습니다.

7. Changes and contact

Changes to this policy are published on this page with a new effective date. Questions: the project owner at github.com/betona1.

변경 사항은 이 페이지에 시행일과 함께 게시합니다. 문의는 깃헙 프로젝트 소유자에게.
